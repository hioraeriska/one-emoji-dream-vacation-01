One emoji, one dream vacation. `main.py` writes exactly one emoji — a desert
island 🏝️ — to `/output/entry.txt`, nothing else. The entry is judged by a
travel-editor judge that picks the emoji that most makes a stranger want to
book the trip: a desert island is the postcard of the dream itself, specific
and instantly readable, not just any beach.

Run it:

```sh
python3 main.py   # writes $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```
